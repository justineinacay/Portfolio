PORTFOLIO / PRIVACY

Privacy & analytics.

This site measures aggregate visits and interactions only after the analytics backend is configured. It does not sell visitor information or store names, email addresses, raw IP addresses, or full browsing URLs in the first-party event database.

What can be measured

Page views, estimated unique browser sessions, which public portfolio pages were opened, clicks to the résumé or contact links, and the referring website's domain (where available). These help improve portfolio content and usability.

A temporary random session identifier is held in your browser's sessionStorage. The server stores only a salted hash of that identifier. It is not a reliable count of unique people. Page-view totals may include repeat visits or automated traffic.

Your choice

You can disable this portfolio's optional analytics in this browser. Global Privacy Control and Do Not Track settings are also respected.

Optional Cloudflare Web Analytics

The site owner may independently enable Cloudflare's privacy-focused aggregate Web Analytics service. If enabled, the site loads a Cloudflare performance beacon. No Cloudflare beacon loads unless its configuration token is explicitly set.
