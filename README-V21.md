# Justine Inacay Portfolio V21 — Premium Motion Refinement

This release **preserves the approved V19/V20 layout, photography, typography, JL monogram, sections, links, and creative work.** Only background and motion treatments have been updated.

## Changes

- Replaced the former animated topographic/contour background with a restrained **strategy pathways** Canvas 2D animation: subtle grid, connected curves, signal dots, and soft light. The background stays behind content, and is less intrusive on mobile.
- Refined headings with word-by-word editorial reveal; supporting paragraphs follow in sequence.
- Improved scroll-triggered card entrances: small lift, slight perspective, soft blur that settles smoothly, and restrained stagger.
- Polished hover depth and buttons without adding image cropping or changing card layouts.
- Kept the approximately 1.45-second circular light/dark reveal.
- Preserved accessible content without JavaScript and all motion-reduction preferences.

## How to open

Extract the whole ZIP and open `index.html` in your browser, keeping the `assets`, `case-studies`, and `notes` folders beside it. The separate **V21 Interactive.html** is the convenient offline edition for full-page viewing without those folders.

## Deployment

Upload the contents of the extracted folder to your existing GitHub Pages repository. GitHub Pages can serve the `index.html` static site. This file has NOT been published automatically.

## Analytics

The floating visitor preview is preserved but will not display live visitor counts until the existing V18/V19 analytics backend is activated. No fake counters are generated. Refer to `ANALYTICS-SETUP.md` for setup.
