# Justine Inacay — Premium Portfolio V20

This is the approved V19 portfolio design, enhanced with a premium scroll-motion layer. **The layout and content have not been redesigned.**

## Open / publish
- For a normal website, place all files and folders at your GitHub Pages repository root. `index.html` is the entry point. Do not separate `assets/` from it.
- To view without deploying, open `index.html` in a browser after extracting the ZIP.
- A separate self-contained `Justine_Inacay_Portfolio_V20_Premium_Full.html` is provided for offline use.

## What's new in V20
`assets/premium-motion-v20.css` and `assets/premium-motion-v20.js` add on-scroll text and card reveals, staggered card motion, subtle lift, premium shadows, and accessible reduced-motion behavior. Existing content, imagery, official logo assets, projects, case studies, themes, and visitor counter stay as in V19.

## Visitor analytics
The floating visitor widget is preserved, but the live statistics only appear after you configure the V19 analytics backend. No fake visit totals are shown. Follow `ANALYTICS-SETUP.md`.
