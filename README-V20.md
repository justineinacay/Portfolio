# Justine Inacay · V20 Premium Motion

This release builds directly on the approved restored V19 design. It does not replace the navigation, photographs, campaigns, case studies, portfolio content, project cards, or analytics backend.

## What's new
- Scroll-triggered reveal of section headings, work cards, tool cards, notes, and project cards.
- Subtle card elevation and refined link and button motion.
- Staggered timing for rows of cards.
- Motion respects system Reduced Motion and does not require a framework.
- Same behavior in the editable multi-page website and in the offline standalone HTML.

## Use
Deploy the full website folder on GitHub Pages with `index.html` at the repository root. The visitor counter still needs the original V19 analytics backend to be connected to show real counts.

The CSS and JS changes are isolated to `assets/premium-motion-v20.css` and `assets/premium-motion-v20.js`.
